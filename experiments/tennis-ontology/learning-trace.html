Tennis Ontology: What Was Added

Read this left to right. Docker starts a Fuseki server, creates a dataset named /tennis, the loader uploads tennis.ttl, and SPARQL asks questions against those triples.

1. Docker starts Fuseki docker compose up -d
2. Dataset is created FUSEKI_DATASET_1: tennis
3. Ontology is uploaded POST tennis.ttl to /tennis/data?default
4. Query returns rows SELECT player, match, tournament, year

Docker Compose: creates the local server

services:
  fuseki:
    image: stain/jena-fuseki:latest
    platform: linux/amd64
    ports:
      - "3030:3030"
    environment:
      ADMIN_PASSWORD: tennis
      FUSEKI_DATASET_1: tennis

Loader: puts the ontology into Fuseki

curl -u admin:tennis \
  -X POST \
  --data-binary @tennis.ttl \
  -H 'Content-Type: text/turtle' \
  'http://localhost:3030/tennis/data?default'

SPARQL: asks a competency question

SELECT ?playerName ?matchName ?tournamentName ?year
WHERE {
  ?player tennis:winnerOf ?match ;
    rdfs:label ?playerName .
  ?match tennis:playedAtTournament ?tournament ;
    tennis:year ?year ;
    rdfs:label ?matchName .
  ?tournament a tennis:GrandSlamTournament ;
    rdfs:label ?tournamentName .
}
